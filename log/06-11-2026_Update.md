## 1. Ringkasan Singkat (TL;DR dalam 1 Menit)

1. **Arah Baru ("Build With AI, Solve For Bali")**:
   - Scope disempitkan secara disiplin: **Khusus Aksara Bali, Web Only**.
   - Modul perangkat keras (*Tactile Pad*, RFID, Web Serial) dinonaktifkan dari antarmuka karena juri menilai aplikasi web yang bisa diuji jarak jauh.
   - Aksara Lontara dan Sunda disembunyikan dari antarmuka publik (fokus murni budaya Bali).
2. **AI Tidak Lagi Butuh Server Python untuk Jalan**:
   - Model klasifikasi EfficientNet-B0 (30 kelas Aksara Bali) kini berjalan **100% langsung di dalam browser pengguna menggunakan ONNX Runtime Web (WASM)**.
   - Kalian **tidak perlu** menyalakan server FastAPI/Python saat menjalankan atau mendemokan web. Cukup jalankan satu perintah: `cd web && npm run dev`.
3. **Pembersihan Konten Palsu (Kepatuhan Anti-Diskualifikasi)**:
   - Panduan juri DigiFest melarang keras pemalsuan demo atau skor fiktif. Seluruh skor statis palsu (`87/100`, klaim *Urutan Goresan 96%*, *CNN/ViT*, *248 Glif*, dll.) telah diganti dengan riwayat latihan nyata pengguna dan label transparansi simulasi yang jujur.
4. **Audit QC & Aksesibilitas Selesai**:
   - Seluruh 16 rute aplikasi web telah diperbaiki tata letaknya, tombol macet telah dibuka, panel kanan yang meluap telah dikunci agar muat di layar laptop, dan background tematik Full HD baru telah dipasang.

## 3. Arsitektur Teknis Baru: *Client-Side AI Inference*

Salah satu perubahan paling revolusioner di versi DigiFest ini adalah cara AI bekerja:

```
[ Pengguna Menulis di Kanvas ]
             │
             ▼
[ Ekstraksi Bounding Box & Citra Kanonik (128×128 Grayscale) ]
             │
             ▼
[ ONNX Runtime Web WASM (Berjalan Langsung di Browser Klien) ]
             │
             ├──► Output: Top-3 Prediksi Kelas & Probabilitas
             ├──► Evaluasi: Lulus jika probabilitas ≥ Ambang Batas (75%)
             └──► Tanpa Mengirim Data Gambar ke Server Luar (Privasi Aman)
```

### Keuntungan Bagi Tim:
- **Juri tidak akan mengalami error server mati**: Saat juri menguji web di laptop atau HP mereka, komputasi AI dilakukan oleh CPU/WASM perangkat mereka sendiri. Web tidak akan *down* hanya karena server laptop kita mati atau koneksi Wi-Fi putus.
- **Biaya & Kompleksitas 0**: Tidak perlu menyewa VPS GPU/Python untuk hosting backend AI. Cukup deploy web Next.js ke Vercel!

## 4. Rincian Perbaikan Fitur & Halaman (Walkthrough 16 Rute)

### A. Beranda (`/`) & Navigasi Utama
- **Masalah Lama**: Tombol Hero CTA *"Mulai Petualangan Aksara"* tidak bisa diklik karena tertutup lapisan transparan `section2`. Navbar juga sering tidak langsung muncul di tab baru.
- **Perbaikan**: Penumpukan layar diperbaiki dengan `marginTop`, z-index tombol dinaikkan ke `z-30` (langsung responsif di layar desktop maupun mobile `375×812`), dan status intro disimpan pada cookie `aksantara_intro_seen` sehingga Navbar langsung terlihat setelah intro ditutup atau dilewati.

### B. Halaman Tentang Kami (`/tentang`) & 404 Not Found
- **Masalah Lama**: Halaman `/tentang` meminjam background landing page yang digelapkan, dan halaman `404` memakai background portal biasa.
- **Perbaikan**: Diberikan background tematik Full HD baru:
  - `/tentang` → `bg-tentang.webp` (*Ilustrasi Balai Belajar Tradisional & Meja Nyurat Lontar*).
  - Halaman 404 (`not-found.tsx`) → `bg-not-found.webp` (*Ilustrasi Reruntuhan Candi Bali & Papan Petunjuk Jalan Tersesat*).

### C. Autentikasi (`/auth`) & Portal Belajar (`/mulai`)
- **Masalah Lama**: Formulir pendaftaran terpotong di layar kecil, input formulir tidak memiliki atribut label aksesibel, dan tombol mode tamu belum terintegrasi bersih.
- **Perbaikan**: Formulir registrasi diberi scroll mandiri jika layar sempit, seluruh input dilengkapi `<label htmlFor>`, dan tombol **"Masuk sebagai Siswa (Tamu)"** memungkinkan juri langsung mencoba seluruh fitur dalam 1 kali klik tanpa perlu membuat akun Supabase terlebih dahulu.

### D. Katalog Glif (`/latihan/web/bali`) & Studio Kanvas (`/latihan/web/bali/[karakter]`)
- **Masalah Lama (Kritis)**: Pada katalog latihan, panel samping kanan (*Konsonan Dasar*) memiliki tinggi tak terbatas. Akibatnya, tombol utama *"Latih Karakter"* berada di luar layar bawah laptop. Pengguna harus scroll halaman penuh sampai mentok ke bawah baru tombolnya kelihatan.
- **Perbaikan**: Panel kanan dikunci dengan pembatas tinggi `lg:max-h-[calc(100dvh-6rem)] flex flex-col`. Konten tengah glif dapat digulir mandiri, dan tombol **"Latih Karakter Ha →"** di-pin di bagian bawah sehingga **100% langsung terlihat dan dapat diklik saat pertama kali halaman terbuka (`scrollY = 0`)** pada laptop 1366×768 maupun 1280×720.

### E. Halaman Hasil Latihan (`/latihan/web/hasil`) & Profil Siswa (`/profil`)
- **Masalah Lama**: Menampilkan data nilai bohong statis (`87/100`, *Stroke Order*, *Trinitas*).
- **Perbaikan**: Halaman hasil kini membaca riwayat sesi nyata pengguna dari penyimpanan lokal browser (`localStorage`/`sessionStorage`). Jika pengguna belum berlatih, muncul tampilan *Empty State* yang jujur dan mengajak berlatih. Halaman profil menampilkan statistik akumulatif nyata (`X / 30 Glif`, `X / 9 Bintang Epos`). Tombol *Keluar* (`logout`) juga sudah berfungsi normal.

### F. Mode Cerita Calon Arang (`/cerita` & `/cerita/calon-arang/bab/1`)
- **Masalah Lama (Kritis)**: Pada Bab 1 Adegan 6 (Tantangan Kanvas Mini), kode memanggil fungsi evaluasi tanpa mengirimkan citra canvas, menyebabkan fallback ke server Python yang mati dan memicu error `HTTP 503 Service Unavailable` (*soft-lock* cerita macet tidak bisa lanjut).
- **Perbaikan**: Komponen `challenge-canvas-mini.tsx` kini mengekstrak data piksel kanvas `canvasRef.current.getImageData(...)` dan mengevaluasinya langsung menggunakan ONNX WASM di browser. **Nol error 503**, umpan balik AI muncul seketika, dan Bab 2 otomatis terbuka saat Bab 1 diselesaikan.

### G. Balairung Pengampu / Dashboard Guru (`/guru/dashboard` & `/guru/siswa/[id]`)
- **Masalah Lama**: Penuh dengan klaim palsu (*CNN/ViT*, *Urutan Goresan: 96%*, *Sulapa Eppa*, *248 Glif*), dan URL siswa fiktif (`/guru/siswa/999`) menampilkan data siswa lain tanpa peringatan.
- **Perbaikan**: 
  - Dipasang banner transparansi kuning-emas berstandar juri di bagian atas: *"Mode Simulasi Kelas — Contoh Data Pengampu (Ilustrasi Analitik Kelas Bali DigiFest 2026)"*.
  - Seluruh metrik diselaraskan ke 30 kelas model Aksara Bali.
  - Memanggil fungsi resmi Next.js `notFound()` jika ID siswa tidak terdaftar, sehingga membuka `/guru/siswa/999` otomatis memunculkan halaman 404 yang benar.

## 5. Panduan Cara Menjalankan & Menguji Proyek

### A. Menjalankan Aplikasi Web (Satu-satunya yang wajib)
Buka terminal PowerShell di folder proyek:
```powershell
cd web
npm run dev
```
Buka peramban di: `http://localhost:3000`.

### B. Menguji AI Kanvas
1. Masuk ke `http://localhost:3000/auth` → klik **"Masuk sebagai Siswa (Tamu)"**.
2. Pilih jalur **Latihan Menulis Aksara Bali** → klik karakter **Ha**.
3. Gambar bentuk karakter di kanvas → klik **"Evaluasi Goresan AI"**.
4. Model akan memuat runtime WASM secara otomatis dan memberikan skor probabilitas Top-3 secara instan.

### C. Menjalankan Unit Test Preprocessing Python (Opsional untuk AI)
Jika teman-teman ingin menguji skrip preprocessing citra AI di folder `ai/`:
1. Aktifkan virtual environment yang sudah tersedia di repositori:
   ```powershell
   .\ai\deployment\venv\Scripts\Activate.ps1
   ```
2. Jalankan pengujian unit:
   ```powershell
   python -m pytest ai/tests/test_preprocess.py
   ```
