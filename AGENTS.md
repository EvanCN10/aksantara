## Repo map
| Path | Purpose |
|---|---|
| `web/` | Next.js 16 app (the deliverable). Must stay deployable on its own. |
| `ai/` | Training, evaluation, export and canvas-collection harness for the Aksara Bali classifier. |
| `supabase/` | Database schema. |
| `docs/` | Context, setup, AI contract, migration plan, disclosure, usage log, contest guidebook. |

## Commands
```bash
cd web && npm ci          # npm is the only package manager (package-lock.json)
npm run dev               # http://localhost:3000
npx tsc --noEmit          # typecheck (there is no lint script)
npm run build
python -m pytest ai/tests # from repo root
```

## Boundaries
- Scope is **Aksara Bali, web only**. Do not re-add other scripts or hardware.
- Never show mock or hard-coded results as if they came from the model or the database.
- Never commit secrets. Only `web/.env.example` with variable names.
- Record significant AI-assisted work in [`docs/ai-usage-log.md`](docs/ai-usage-log.md).
- The block between `BEGIN:nextjs-agent-rules` and `END:nextjs-agent-rules` in `web/AGENTS.md` is generated by `next dev`; leave it.
