## Approach

### 1. Tetapkan ruang kelas gabungan tanpa menyentuh source manifests
1. Di `ai/train.py`, tambahkan `experiment_scripts(script: str) -> tuple[str, ...]` dan `experiment_view(labels: dict, split_rows: list[dict], script: str) -> tuple[list[dict], list[dict]]`. Target individu memakai representasi/order existing. `combined` memakai urutan eksplisit `('lontara','sunda','bali')`, bukan urutan dict atau runner.SCRIPTS.
2. Derive offsets dari frozen lengths: Lontara0..113, Sunda114..143, Bali144..173. Copy label asli, tambahkan `script`, `source_class_id`, `namespaced_label=f'{script}:{source_label}'`; ganti `class_id` dalam copy menjadi global ID. Pertahankan source_label persis, termasuk Ke/Ke_, ae/e, kapitalisasi/spasi. Copy valid split rows saja, tambahkan source_class_id dan remap class_id; pertahankan row.script asli, sample_id/path/partition/group_id/writer_id/byte hashes. Jangan namespace leakage groups atau membuat split baru.
3. `context()` memvalidasi seluruh original hash dan korespondensi split-versus-audit SEBELUM membuat view. Untuk combined, semua3 source harus ready dan class IDs contiguous; validasi union memakai validate_partitions. Actual experiment harus174 kelas. Missing source/coverage, invalid ID, atau ancestry lintas partition: error eksplisit, tidak memperbaiki/mengurangi scope diam-diam.
4. Combined ctx mendapat `class_space={version:'script-union-v1',scripts:[...],labels:[...],class_space_hash:...}`; hash adalah digest object tanpa field hash. Tambahkan hanya combined `ctx['hashes']['class_space_hash']`. Dataset/label/split hashes original tetap unchanged; specialist identity tetap existing.
5. `permission(ctx, script, action, samples)` tetap signature existing. Untuk combined, kelompokkan berdasarkan row.script asli lalu jalankan policy existing per source; return map keyed source. Jangan membaca provenance['combined'], mengada-adakan lisensi, atau mengembalikan gate Sunda/Bali yang sudah dibuka user.
6. Identity run/resume mengambil ctx hashes seperti existing. `evaluate.load_candidate`, `evaluate.select_pilot_loss`, dan `train.validate_initialization` wajib memeriksa class_space_hash ketika ctx/identity combined; mapping yang missing/berbeda ditolak. `persist_predictions` dan `evaluate.run` menyertakan class_space pada selection.json/predictions.json; tulis `class-space.json` di combined run untuk konsumsi manusia. CSV combined menambahkan script/source_class_id/namespaced_label; CSV individu unchanged.
7. Di `ai/runner.py.parser`, perluas --script menjadi sumber+combined HANYA untuk train/evaluate. SCRIPTS sumber, audit/split, queue riset lama, Kaggle builder, ensemble/export tetap source-only. Combined training hanya stage supervised/source data; reject canvas/distill/initialize/include-canvas untuk combined. Combined evaluation tahap ini hanya selection/calibration; jangan membuka release-test melalui bypass frozen_test_guard. Existing context callers pada colab_notebook, ensemble, evaluate, export, runner.pilot_winners tetap signature-compatible; optional class-space guard tidak mengubah perilaku tiga source.

### 2. Nilai classifier gabungan tanpa oracle aksara
1. Refactor bagian classification-only di `ai/evaluate.py` menjadi `prediction_metrics(labels: np.ndarray, predictions: np.ndarray, classes: int, *, metric_class_ids: tuple[int, ...] | None = None) -> dict`. Reuse sklearn confusion_matrix/f1_score existing. Extend `classification_metrics(logits, labels, classes, *, metric_class_ids=None)` untuk memanggil helper tersebut, lalu tetap menambahkan calibration_metrics/loss seperti existing. Default None mempertahankan semua caller yang ada di train/ensemble/export/evaluate.
2. metric_class_ids harus nonempty, unique, in-range; true labels untuk subset harus berada di IDs itu. Confusion matrix dan predicted IDs tetap seluruh174. F1/min recall memakai denominator kelas source yang diminta, bukan174 kelas saat hanya menilai Sunda. Balanced accuracy memakai supported requested classes; missing requested classes dicatat. Empty/nonfinite/misaligned inputs error eksplisit.
3. Tambahkan `combined_metrics(logits: np.ndarray, labels: np.ndarray, rows: list[dict], class_space: dict) -> dict`: overall174-class metrics, per_script metrics memakai IDs source, equal-script mean macro-F1/top1, dan cross_script_confusion3×3 dengan order Lontara/Sunda/Bali, error_count/error_rate. Softmax/argmax selalu174 logits tanpa masking berdasarkan ground-truth script. Prediksi Sunda→Lontara tetap error pada Sunda. Integrasikan ke evaluate.run; epoch selection engine tetap overall macro-F1 existing, bukan metric baru.
4. Tambahkan `compare_specialists(specialist_runs: dict[str, Path], combined_run: Path, combined_ctx: dict) -> dict` di evaluate.py. Baca best selection.npz/selection.json/manifest.json dari3 explicit specialists dan combined. Verifikasi complete/full/non-smoke/mobile/seed42/128/supervised, actual recipe, preprocessing/source hashes, checkpoint checksum, unique sample IDs dan exact partition membership. Join berdasarkan sample_id; jangan menganggap order array sama. Missing/foreign/duplicate samples atau wrong widths/labels error.
5. Remap specialist local argmax/labels ke174 dan gunakan prediction_metrics untuk aggregate confusion/F1, BUKAN merata-ratakan3 F1 lalu menamainya global. Tampilkan global class-weighted macro-F1 dan equal-script mean secara terpisah. Baseline specialists berlabel `script-known routing`; nol cross-script error adalah konsekuensi routing, bukan kemampuan deteksi aksara. Gabungan berlabel `script-unknown174`. Jangan gabungkan114/30/30 raw logits menjadi network palsu atau menghitung confidence aggregate palsu.
6. Hasil awal menggunakan selection artifact yang sama untuk seluruh comparison dan diberi `provisional: true`, `partition:'selection'`, bukan test accuracy. Simpan overall/per-script confusion, macro-F1, top1, balanced accuracy, min recall, source/class/sample counts, selected loss dan best epoch. Calibration/test/export baru tidak diperlukan untuk membandingkan empat model ini; existing calibration evaluator tetap berfungsi jika dipanggil eksplisit dan tidak dipakai memilih pilot.
